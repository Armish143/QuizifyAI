# QuizifyAI

A simple quiz website where you type a topic and get multiple-choice questions to answer, with an instant score.

Built with plain **HTML, CSS, JavaScript and Bootstrap** (no framework).

## Features
- Enter a topic (e.g. science, history, computers) and choose how many questions
- Questions are fetched from the free [Open Trivia DB](https://opentdb.com) API
- Pick an answer and see instantly if it is correct
- Responsive layout (works on mobile and desktop)

## How to run
1. Download or clone this repo
2. Open `index.html` in a browser (or use the VS Code "Live Server" extension)
3. Go to the **Quiz generator** page, type a topic and click **Generate Quiz**

## Supported topics
general knowledge, books, film, music, science, computers, mathematics, sports, geography, history, politics
